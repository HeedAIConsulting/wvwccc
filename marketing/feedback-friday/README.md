# Feedback Friday — testimonial post standard

The house format for sharing client testimonials on socials. Every testimonial ships in
two formats so it works with sound off and on:

1. **Typewriter video** — the review types out character by character over a dark
   background with gold stars and a blinking cursor. Silent by design; viewers read
   along to the end. Generated by the scripts in this folder.
2. **Avatar video** — a spokesperson-style AI creator speaks the review aloud
   (Higgsfield `ugc-flow` pipeline, Seedance native speech) with word-timed captions
   burned in, so the words are spoken and typed simultaneously. Framed as "in our
   client's words" with an on-screen attribution — the avatar quotes the client, it
   never impersonates them.

## Rendering the typewriter videos

```bash
pip install Pillow imageio-ffmpeg
python3 typing_video.py            # 1080x1350 (4:5) feed version
python3 typing_video_vertical.py   # 1080x1920 (9:16) Stories/Reels version
```

Edit the `BODY` and `ATTR` constants at the top of the script for each new
testimonial. The layout auto-shrinks the font to fit longer reviews. Output is an
H.264 MP4 at 24fps, ~18s, silent.

## Caption template

> ⭐⭐⭐⭐⭐ Feedback Friday!
>
> Nothing beats ending the week with words like these. A huge thank you to
> [name] and the team at [Client] for this 5-star review.
>
> Thank you, @[Client]! We are proud to be your partner and excited for what
> comes next. 🙌
>
> #FeedbackFriday #ClientLove #FiveStarReview #ClientTestimonial

Type the `@` mention in the platform's native composer so it becomes a real tag —
APIs cannot create clickable tags.

## Cadence

Posts go out Fridays at 9:00 AM ET.
