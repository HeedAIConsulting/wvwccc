Image Library

🖼 Every image you've uploaded

Upload a logo or photo once and reuse it anywhere — event flyers, sponsor logos, homepage graphics, member profiles. Anything you upload elsewhere on the console lands here automatically, and every image box now has a 📁 Library button next to it so you never have to hunt for the file again.

Tip: give each image a clear name and a tag or two (council, sponsor, mixer, breakfast) — that's what the search box looks at. Names save as soon as you click out of the box.
